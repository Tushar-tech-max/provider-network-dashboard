# 🚀 Provider Network Status Dashboard

Interactive dashboard built using **SQL and Power BI** to analyze healthcare provider network status.

## 📊 Features

* KPI cards for key metrics
* Donut chart for network distribution
* Slicers (City, Specialty, Status)
* Detailed table view

## 🧠 Insights

* Majority providers are in-network
* Some providers are out-of-network
* Coverage varies by city

## 🛠️ Tools

SQL | Power BI | Data Visualization
